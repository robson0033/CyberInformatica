# Cyber Informática

Projeto responsivo em HTML, CSS e JavaScript inspirado no layout enviado.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.

## Personalização rápida
- Troque o número `5511987654321` nos links do WhatsApp.
- Edite endereço e horários no rodapé.
- Substitua as imagens na pasta `assets`.
- Altere cores no início do arquivo `style.css`, dentro de `:root`.
